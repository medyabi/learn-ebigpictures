Hybrid lab access

Team guide2 min read

Each engineer has a personal Windows Server 2025 VM for the hybrid labs. You reach it from anywhere over HTTPS, through our Remote Desktop Gateway at labs.ebigpictures.com. Your password arrives privately from Mohamed, never on this page.

Connect in four steps

  1. Find your user name in the table below and download your connection file.
  2. Double-click the .rdp file. On a Mac, iPad or phone, open it with Microsoft's free Windows App.
  3. At the security warning, tick Clipboard if you want copy-paste, then click Connect.
  4. Sign in twice, with the same password both times: first the gateway as RDGW01\mtsNN, then your lab VM as .\mtsNN. For example RDGW01\mts03, then .\mts03.

About the security warning

Note

"Unknown publisher" is expected. It appears because the connection file isn't digitally signed. The connection itself is encrypted over HTTPS to labs.ebigpictures.com with a trusted certificate. Check that the gateway server shown is labs.ebigpictures.com, then click Connect.

If something goes wrong

"There was a problem connecting to the remote resource"
Check that you typed the gateway sign-in as RDGW01\mtsNN. If you're on the same office network as the lab, try from another connection, such as a phone hotspot.
Your account is locked
After Lab 9 (security baseline), three wrong passwords lock your VM account for 15 minutes. Wait, then sign in carefully.
You broke your VM during a lab
That's fine. Ask Mohamed: a VM is reset to its clean baseline in a few minutes.
Something else
Send Mohamed the error message, or a screenshot of it, and the time it happened.

Don't forward your password outside the team.
