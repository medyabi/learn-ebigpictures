How every lab works

  1. The situation. A customer question or an attacker's move: why this lab matters.
  2. The concepts. Just enough theory, in plain words, with an analogy.
  3. Step by step. Build it on your own VM, with the exact commands.
  4. Prove it. A verification command or a portal view that shows it works.
  5. Takeaway. Talking points for the customer, or the one idea to remember.

What you need

Hybrid track

A Windows Server 2025 VM (your instructor provides one), an Azure subscription where you can create a resource group, and about two days.

Security track

A Hyper-V host for four Generation 2 VMs with Secure Boot and a virtual TPM, plus Azure and Microsoft 365 trials for the cloud chapters.
