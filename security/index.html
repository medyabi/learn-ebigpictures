Windows Server 2025 Security Lab

Article6 min read

25 hands-on labs that follow one idea: show the attack first, then build the control that stops it, then prove that it works. Each lab has a hacker scenario, the concepts, how the control breaks the attack, a step-by-step build with verification commands, and one key takeaway.

Important

Most of the time attackers do not break in, they log in: a weak password, a hash stolen from memory, an admin account with too many rights. This lab closes those doors one by one, with tools already in Windows Server and Azure.

⚠️ Lab environment only. Several labs lock accounts, change boot or authentication behaviour, or force BitLocker recovery. Run them on your own isolated virtual machines, with checkpoints, never on production systems. The attacks are simulated with harmless commands (failed sign-ins, a test local admin, a test firewall rule, …); this repository contains no exploit code.

The lab

Four VMs on Hyper-V (all Generation 2, Secure Boot, virtual TPM) and an Azure subscription for the cloud chapters.

Start here

  1. Read Welcome and lab setup: VM table, domain, users, RSAT, Azure prerequisites and the extra setup the labs assume (switch, Servers OU, Policies$ share).
  2. Take a checkpoint named Baseline of every VM.
  3. Do the labs in order (later labs reuse earlier results; dependencies are listed in the setup doc).
  4. At the end, use the attack → control map as a self-test: cover the middle column and name the control.

What you need

Host A Hyper-V host able to run four VMs at once (three Windows Server 2025, one Windows 11 Enterprise), all Generation 2 with Secure Boot and a virtual TPM
Azure Free trial subscription, resource group seclab-rg, Microsoft Entra ID P2 trial (needed by the Azure labs: 1.6, 2.2, 4.1 to 4.4, 6.3)
Microsoft 365 E5 trial for Defender for Identity (Lab 3.4)
Time The labs that need Azure or Microsoft 365 trials are the ones that expire: plan them together

Labs that need no Azure or Microsoft 365 subscription (a few still need internet, for example the SmartScreen test page): 1.1 to 1.5, 2.1, 2.3, 2.4, 2.5, 3.1 to 3.3, 5.1 to 5.3, 6.1, 6.2. Labs that need Azure and/or Microsoft 365: 1.6, 2.2, 3.4, 4.1 to 4.4, 6.3.

Scripts

scripts/ holds every command and KQL query from the labs, with the sentence that introduces it as a comment. They are snippets to run one by one, on the machine named in the lab, not scripts to run as a whole. All PowerShell files were checked with the PowerShell parser for syntax errors; they were not executed here (no Windows Server lab in this repository's build), so test in your own lab.

Source and status

The lab text comes from the course document How to Master Windows Server Security (author: Mohamed), converted to Markdown without changing its content, except for the few places marked ⚠️ Added by this repository, listed in docs/REVIEW-NOTES.md together with points to double-check against current Microsoft documentation. Product names and portal paths change often: where the course adds a 2025 note, it is kept as a 📌 note.
